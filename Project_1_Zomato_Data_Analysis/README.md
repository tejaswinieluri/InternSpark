
# Zomato Restaurant Data Analysis

## Internship

InternSpark

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Zomato restaurant dataset to understand restaurant ratings, cuisines, locations, pricing, online ordering, and restaurant characteristics.

The analysis uses Python-based data cleaning, statistical analysis, and visualization techniques to identify useful patterns and insights from the dataset.

## Objectives

* Analyze restaurant ratings and rating distribution
* Identify popular cuisines
* Analyze restaurant locations
* Study restaurant pricing patterns
* Compare ratings based on online ordering
* Analyze restaurant types
* Identify relationships between price, votes, and ratings
* Generate actionable recommendations

## Dataset

The project uses the Zomato restaurant dataset available on Kaggle.

Dataset source: Kaggle – Zomato Restaurant Dataset

## Key Results

* Total restaurants after cleaning: **35,485**
* Average restaurant rating: **3.73/5**
* Rating range: **1.8–4.9**
* Average cost for two people: **₹588.11**
* Total votes: **10,517,255**
* Most common cuisine: **North Indian**
* Highest-rated location among locations with at least 50 rated restaurants: **Lavelle Road – 4.19/5**
* Average rating with online ordering: **3.75/5**
* Average rating without online ordering: **3.71/5**
