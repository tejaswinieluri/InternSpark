# Instagram Engagement Analysis – Alfido Tech

## Project Overview

This project analyzes Instagram post engagement to identify patterns in likes, comments, content types, hashtags, follower-network signals, and posting activity.

The analysis was completed as part of the Alfido Tech virtual internship task.

## Objectives

* Analyze Instagram post engagement
* Calculate likes, comments, and total engagement
* Calculate engagement relative to follower-network size
* Analyze content types
* Analyze hashtag performance
* Examine posting schedule information
* Identify follower-growth signals
* Develop a practical Instagram content strategy

## Dataset

The dataset contains Instagram-style information across multiple CSV files:

* `photos.csv`
* `likes.csv`
* `comments.csv`
* `follows.csv`
* `users.csv`
* `tags.csv`
* `photo_tags.csv`

## Key Analysis

The project analyzes:

1. Post engagement
2. Likes and comments
3. Engagement rate
4. Content/photo types
5. Hashtag performance
6. Follower-network size
7. Posting-time information

## Key Findings

The dataset contains 257 posts with an average of approximately 34.17 likes, 29.14 comments, and 63.31 total engagements per post.

Photos, videos, and carousels showed relatively similar average engagement in the available data.

The dataset's recorded timestamps are concentrated at the same Thursday 08:04 time, so the analysis cannot establish a statistically reliable optimal posting day or hour.

## Strategy

The project proposes a testing-based content calendar for Alfido Tech focused on:

* Educational technology content
* Project showcases
* Short-form videos
* Student/internship content
* Interactive posts
* Relevant hashtag groups
* Posting-time experiments
